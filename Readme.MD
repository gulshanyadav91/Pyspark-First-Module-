# PySpark First Module 🚀

This repository contains my beginner-level learning and practice of **PySpark** using Jupyter Notebook.

## 📚 Topics Covered
- Introduction to PySpark
- SparkSession and SparkContext
- Basic PySpark operations
- Hands-on coding and practice

## 🛠️ Technologies Used
- Python
- PySpark
- Jupyter Notebook

## ▶️ Getting Started
Install PySpark before running the notebook:

```bash
pip install pyspark
```

Open `Pyspark_first_learning.ipynb` in Jupyter Notebook and run the cells.

To build a strong foundation in PySpark and progress toward Data Engineering.
